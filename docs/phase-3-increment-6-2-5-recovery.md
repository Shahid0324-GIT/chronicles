# Semantic qualification and scene recovery

The reviewer can confirm a proposition’s modality and select an exact licensed archive unit. It no longer has to repeat the extracted modality label or transcribe a passage to approve a decision. A conflicting observation still blocks qualification. An evidence ID must resolve inside that candidate’s offered evidence. Final prose grounding still checks entailment against the archive.

The reconstruction records provider failure, incomplete response, missing witness, invalid witness, missing modality, unsupported meaning, contradiction, and unresolved identity separately. Eligible sibling decisions remain cached. Unavailable decisions leave essential review pending. They establish no factual rejection and do not trigger another extraction of the same candidate.

Continuation restores bound candidates and requalifies actionable rows. When an essential proposition is unsupported, the existing recovery pass can rederive or split it from direct archive evidence. An archive-backed revision preserves the planning clause, fact ID, and canonical data. Reader grounding uses the actual bound archive, so the old clause’s wording does not supply evidence for a correction.

The scene gate includes the plan’s essential scopes and central propositions in the controlling narrative source. An uncertain secondary-source placement can stay an explicit gap. Authored paragraphs and successful citation alignments count toward continuation, and unambiguous transport prefixes resolve only within the current scene’s citation allowlist.
