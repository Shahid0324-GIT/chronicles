# Semantic reconstruction and narrative flow

Chronicles keeps evidence references, participants, the status of a proposition, and supported ordering stable throughout the narrative pipeline. Expression remains flexible. A scene can combine an action, a participant’s belief, and a resulting change in circumstance in one paragraph. The account still has to preserve whose belief it was and which outcome the archive actually establishes.

## What changed

- Extraction can represent states, speech, beliefs, emotions, decisions, promises, and revelations. It only assigns roles relevant to the proposition. A state can qualify without an actor.
- Short context IDs resolve to licensed archive units inside the current evidence window. An unknown ID supplies no evidence. The remaining proposition still goes through review against its bound archive.
- Qualification checks meaning, modality, and a verbatim witness. It does not ask the reviewer to recreate the entire role map. An incomplete approval is unavailable for qualification and leaves other decisions intact.
- Scene readiness tracks missing essential propositions separately from optional gaps and reviewer availability. Where the source cannot place a proposition, the writer receives it as unordered context. A formal relationship is needed for a claimed cause or historical ordering. Reference order supports presentation.
- The relationship retry considers supported transitions across the plan, including changes between scenes. The writer uses qualified propositions and can combine them into natural prose. Archive-based factual grounding, relationship checks, and publication review remain separate.

Canonical matches still require existing scoped names or aliases. The extractor can use a consistent name within a scene when its evidence identifies the same person. Reliable cross-source alias consolidation remains open.

## Live benchmark

The controlled Romance Dawn run used the existing 54-unit archive and stored development plan. A second pass reassessed the automatic candidates under the stricter semantic review policy. The first pass incorrectly approved a change from a wound below the eye to a wound to the eye. The second rejected it. The test suite also replays the original incomplete provider approval and checks that it stays outside the qualified cache.

The runner stopped at reconstruction. The required rescue outcomes, tavern conflict, and farewell remained incomplete. Several otherwise plausible rows had no usable independent modality assessment. No narrative was written or published. The spoiler-bounded Arc API returned HTTP 200 with pending status and no article. First Voyage was therefore held.
