# Final stabilization workflow

| Stage | Previous behavior | Current behavior |
| --- | --- | --- |
| Development binding | Assertions and archive passages shared numeric aliases. Invalid plans could be reused on a withheld retry. | Distinct aliases bind to exact archive records. The planner receives one bounded retry with the binding error and any unaccounted assertion IDs. The same validator still fences every reference. |
| Reconstruction | Issue lists could serve as the sole readiness check. | Readiness also requires actual qualified scene frames and no missing or pending essential developments. Optional gaps remain visible. |
| Composition and alignment | Whole-section composition was active alongside unused scene composition helpers. | The whole-section writer and resumable sentence alignment remain. The earlier scene assembly helpers were removed. |
| Grounding | An incomplete calibration or a provider switch could discard otherwise usable claim responses. The retired positional reviewer duplicated grounding logic. | Claim observations and calibration decisions are checkpointed separately. The observation records provider, model, evidence dependency, policy, and a response fingerprint. Only that reviewer's completed qualification can release the observation. Retries target unresolved IDs. |
| Editorial review | Editorial assessment stopped when factual grounding was unavailable. | Controlled diagnostics can reuse the existing editorial assessor with the available grounding results. This skips publication-only relationship review and leaves the publication gate closed. |
| Publication | The production gate and diagnostic draft output could be confused. | Both paths use the same reconstruction, composition and review functions. The live endpoint only reads persisted artifacts and the diagnostic output remains separate. |
