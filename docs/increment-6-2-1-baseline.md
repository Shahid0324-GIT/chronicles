Recorded 2026-11-22 before production code changes. No model calls were made for this audit. The existing Docker service and PostgreSQL container were started with their existing volumes; no data was reset. Read-only live reproduction is archived locally in `.tmp/increment621-baseline.json`.

## Reproduced, current failures

The original-manga, chapter-7-bounded view still contains **26 accepted assertions**, three selected reference sources and **zero validated article sections**. Calling the current `ground_understanding` on the stored organization succeeds despite the following order: hat → rescue → independent ambition → request/refusal → fruit → effects. This is a reproduced structural defect, independent of yesterday's provider rate limits.

1. `ArcIntelligence.context` sorts assertions by their fingerprints. That order is a cache convention, not narrative order. The organizer receives `licensed_context`: only numeric assertion IDs and statement strings. It receives neither source passages nor numeric source coordinates.
2. `NarrativeDevelopment` contains a stage, fact IDs and links to earlier keys. `ground_understanding` checks references, key order and accounting, but never checks the proposed story order against evidence, roles, modality or a supported partial order. Thus the wrong order passes.
3. The actual dossier explicitly excludes three kidnapping/intervention assertions as `unrelated` because they concern Higuma. That exclusion removes the conflict needed to explain the retained rescue. Accounting for every assertion did not validate the omission's meaning.
4. Evidence quote offsets are passage-relative. Passage starts occur only inside a formatted locator, rather than typed numeric source coordinates in the reader fact projection. Additional identification/context quotations can precede the actual action anchor. Sorting by the earliest cited fragment would also be wrong: the refusal has introductory context at offsets 0/42 but its action statement is at 768–926.
5. Source captions occur early: the repeated fruit caption and “Shanks saves Luffy's life” are not occurrences at those textual locations. An action anchor must be distinguished from a caption or contextual mention by evidence assessment, not by a story-specific rule.
6. The source account describes the stretching arm before confirming that Luffy **had eaten** the fruit. Occurrence order, observation/revelation and source-account presentation must remain distinct. Simply sorting all quotations into one total order would lose this distinction.
7. The composer forbids additional clauses from quotations and sees only accepted descriptions plus unparsed archive locations. It also omits the unvalidated editorial groups. It therefore has neither a validated progression nor sufficient context to reconstruct one reliably.
8. Character-attribute extraction stores a free-text description. The face-cut assertion preserves a purpose (“to prove”), but its nested intent has no typed clause-level commitment. A prose claim strengthened this to “proves.” A whole-fact occurrence status cannot describe every clause of a compound assertion.
9. `validate_claims` checks citation membership and paragraph reference unions; actual entailment and modality are left to one semantic review. `review_ok` trusts the verdict despite contradictory explanatory text. The saved local review marks the courage claim supported while explaining that success is not established.
10. Current lexical temporal/name bans have already been removed. Their historical failure must not be “fixed” again by adding word-pattern rules. The remaining failure is semantic and structural.
11. A supported decision→plan paraphrase was rejected by a live reviewer. Qualification now explains that distinction, but a later rate-limited cloud call fell back to a local model which failed qualification. These are separate outcomes, not evidence that qualification always works.
12. The latest-20-job outline eviction bug is already fixed and has a regression. Prose and organization policies are already separate. However, the actual generated draft is discarded when qualification/review fails; only review diagnostics survive, so a later eligible job cannot resume that draft. Semantic revision also regenerates the whole section, despite claim indices identifying narrower errors.
13. Existing inference reuse covers extraction/verification with installed model digests; it does not preserve organized section accounts or pending factual/editorial review stages independently. Repeated fresh composition jobs were consequently expensive.
