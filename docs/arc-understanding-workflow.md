# Arc understanding workflow

## Previous production call graph

```text
LangGraph planner → source acquisition and archive → extraction and identity
  → relationship analysis → verification → canonical promotion
  → ArcIntelligence.rebuild
    → provisional ArcPlan establishes sections
    → assign_accepted_scope partitions canonical assertions
    → prepare_developments binds and reviews each section independently
    → reconstruct_arc reinterprets those clauses as semantic frames and scene beats
    → section writer aligns, grounds, repairs and reviews each section
    → stored arc article → existing GET endpoint
```

The planner previously fixed section boundaries before understanding the story. Assertion assignments, development clauses, frame qualification, and prose alignment each asked a model to recover partly overlapping relationships. A valid assertion could be lost at a section boundary or when a model selected a neighboring unit belonging to a different source. Passing an adjacent section's scenes to the writer did not establish verified connections across those sections.

## Replacement production call graph

```text
Scoped canonical archive → broad LangGraph discovery, verification and promotion
  → one arc-wide understanding draft with canonical assertion references
  → independently ground its passages and assess the arc's coverage
  → genuine evidence questions return to the existing research frontier
  → persist the qualified Arc Understanding Document
  → derive a contiguous outline from that document's progression
  → compose a continuous arc article from the document and outline
  → ground article claims and check continuity, coverage and originality
  → stored article → existing GET endpoint
```

Section topics and boundaries are derived after the account qualifies. Article citations are translated through the document to accepted graph assertions and their archived evidence. The research worker still owns provider permissions, execution controls, and progress checkpoints. The earlier section reconstruction remains callable by historical controlled diagnostics. The production worker uses the whole-arc path.
